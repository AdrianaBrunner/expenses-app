Privacidade
Nesta v1, os dados ficam salvos só no dispositivo/ navegador (LocalStorage). Para compartilhar com seu marido, vocês podem usar o mesmo link em PCs/celulares diferentes, mas cada um terá seus próprios dados — a menos que usem a opção Exportar/Importar.

Se quiser que os dados fiquem na nuvem, com login (Firebase Auth + Firestore), consigo montar uma v2.
